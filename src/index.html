Data Sources

Common data sources used in Mining Software Repositories research.

Source Data Provided Description
GitHub Repositories, commits, pull requests, issues, stars Provides information about software development projects and collaboration.
Stack Overflow Questions, answers, tags, reputation Contains developer questions and discussions about programming problems.
JIRA Issues, sprint data, bug reports Tracks software development tasks, bugs, and project progress.
App Stores Reviews, ratings, downloads Provides user feedback and information about mobile applications.
Travis CI / Jenkins Build logs, test results, deployment data Provides information about automated builds and software testing.
Mailing Lists Developer discussions and archives Records communication between software developers.
npm Registry Dependencies, downloads, package versions Provides information about JavaScript packages and their usage.
